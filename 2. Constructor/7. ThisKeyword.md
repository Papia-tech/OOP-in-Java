# This Keyword in Java

## 🔹 Definition

The `this` keyword refers to the **current class object**.
It is used to access current class **variables, methods, and constructors**.

## 🔹 Why Use `this`?

* To resolve naming conflicts between instance and local variables
* To improve code clarity
* To reuse constructors (constructor chaining)

## 🔹 Uses

* Access current class variable
* Call current class method
* Call another constructor using `this()`
