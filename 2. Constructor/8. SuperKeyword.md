# Super Keyword in Java

## 🔹 Definition

The `super` keyword refers to the **immediate parent class object**.
It is used to access the parent class **variables, methods, and constructors** from the child class.

## 🔹 Why Use `super`?

* To access parent class members
* To avoid confusion when parent and child have same names
* To reuse parent class functionality

## 🔹 Uses of `super`

* Access Parent Class Variable: Used when parent and child class variables have the same name.
* Call Parent Class Method: Used when a child class overrides a method and wants to call the parent version.
* Call Parent Class Constructor: Used to initialize parent class properties during object creation
